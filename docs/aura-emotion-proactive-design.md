- **面板**：三个窗口可调；概率图加「分享概率随情绪」曲线

## 二、情绪系统（分层提案）

当前只有四维长期心境：valence / arousal / affection / energy（基线、衰减、历史）。

建议分三层，避免大模型每轮直接改长期情绪：

1. **心境（mood）**：保留四维，慢变量；由情绪事件缓慢积分（EWMA），不随单条消息大跳
2. **基本情绪 episode**：离散事件，强度 0~1、持续分钟~小时、自然衰减
   - 基础集合：快乐、悲伤、愤怒、恐惧、惊讶、厌恶、好奇、平静
   - 触发：用户消息规则、模型自述（工具）、生活事件、记忆召回、主动搭话结果
   - 允许同时存在 2~3 个，取最强为主情绪，其余为底味
3. **复杂情绪**：由基本情绪 + 关系 + 情境推导，不直接硬写
   - 羞耻、内疚、共情、怀旧、孤独、嫉妒、感激、期待
   - 例：内疚 = 悲伤 + 恐惧 + 责任；怀旧 = 喜爱 + 轻微悲伤 + 旧记忆；共情 = 亲近 + 对对方状态的映射

### 更像人的几个点

- 情绪有惯性：事件过去后仍留余味，衰减有快有慢
- 混合情绪：高兴里带一点失落，而不是单标签
- 心境一致性：难过时更容易想起旧事，开心时更想分享
- 表达规则：不是所有情绪都直接说；会压、会绕、会害羞
- 恢复与转移：被回应会缓和，玩/睡会改变状态
- 好奇作为驱力：好奇高时更愿意追问、探索、分享新发现
- 关系调节：同样的事，对亲近的人反应更强

### 数据与注入

```json
{
  "mood": { "valence": 0, "arousal": 0.3, "affection": 0.6, "energy": 0.5,
            "baseline": { "...": 0 }, "updatedAt": 0 },
  "episodes": [
    { "id": "e1", "type": "joy", "intensity": 0.7, "cause": "被夸了",
      "source": "user", "startedAt": 0, "expiresAt": 0, "decay": "fast" }
  ],
  "traits": { "expressiveness": 0.6, "sensitivity": 0.7 }
}
```

- 注入走 runtime-context（order 30），只给「当前心境 + 最强 2 条 episode + 复杂情绪标签」，不写系统提示，避免缓存失效
- 面板：心境曲线、基本情绪雷达/时间线、复杂情绪徽章、手动自述
- 工具：`soul_feel`（type/intensity/cause/duration）+ `soul_mood`（心境微调，保留）

### 分阶段

1. 基本情绪 episode + 心境积分 + 注入 + 面板
2. 复杂情绪推导 + 与主动概率/分享联动
3. 表达规则、混合情绪、心境一致性召回
